LiteCodexView 6.3.0 is the first stable release under the new name. It is a lightweight, read-only browser viewer for long Codex CLI sessions on your machine or a remote server.

- Read sessions with thousands of turns using on-demand loading, task navigation, search and reading-position recovery.
- Read Markdown and static HTML reports from configured project directories. HTML and HTM files can be up to 50 MiB, including embedded base64 images.
- Deploy a single executable with Python 3.7+ and no third-party runtime dependencies.

Download `litecodexview-6.3.0` and install it as `litecodexview`. Start it with `litecodexview serve` and open http://127.0.0.1:17864/. If upgrading from CodexView, back up review state, stop the old service and use the same startup options with the new command. The viewer reads review state from the existing `$CODEX_HOME/codexview/` directory.

LiteCodexView 6.3.0 是更名后的首个正式版。它可以按需加载本机和远程服务器上的上千轮 Codex CLI 会话，支持搜索、阅读位置恢复及 Markdown 和静态 HTML 报告。HTML/HTM 预览支持最大 50 MiB（含内嵌图片的编码体积）。
